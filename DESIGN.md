# Дизайн-система Chateau At Mount

Направление: «напский» редакционный стиль (референсы: BRAND Napa Valley, Realm Cellars,
Epoch). Уникальность важнее «люксовых» шаблонных приёмов.

## Шрифты

- **Заголовки:** Piazzolla (variable, ось opsz), вес 500. Кириллица родная.
- **Текст/UI:** Inter.
- Курсивный Piazzolla — для тэглайнов и «голоса семьи».
- Никаких новых шрифтов без решения владельца.

## Палитра — «вино и известняк»

| Токен | Значение | Роль |
|---|---|---|
| `--bg` | `#f4f1ea` | известняк — светлая основа |
| `--bg-soft` | `#eae5da` | подложки на светлом |
| `--ink` | `#241a1c` | текст, почти-чёрный со сливовым подтоном |
| `--ink-soft` | `#6a5d5e` | вторичный текст |
| `--wine` | `#5e2a33` | **цвет действия** — заливка кнопок на светлом |
| `--accent-dark` | `#6d3440` | винный для киккеров/деталей на светлом |
| `--accent` | `#d0a09b` | пыльная роза — киккеры/детали на тёмном; на страницах вин переопределяется цветом этикетки |
| `--dark` | `#1e1518` | тёмные секции, сливовый (не кофейный) |
| `--clay` | `#8d5843` | обожжённая глина — полотно блока вин на главной |

## Железные правила

1. **Никакого цвета поверх фотографий.** На фото — только белый/монохром:
   текстовые ссылки `.hero-link` с подчёркиванием и стрелкой, никаких залитых кнопок.
2. **Винная заливка живёт только на светлом фоне.** На тёмных секциях кнопка светлая
   (`.section-dark .btn-accent`).
3. **Hero** — композиция вниз-влево, гигантский заголовок, скрим линейный монохромный.
4. **Меню нумерованное** (01–05), языки — текстом с подчёркиванием активного.
5. **Награды** — почётный ряд с медалями, не чипы и не бейджи.
6. Радиусы 2–3px, никаких «пилюль» и кругов с иконками; разрядка (letter-spacing)
   только в САПSLOCK-микролейблах.
7. **Блок вин на главной** — глиняное полотно с горизонтальным проездом (по
   мотивам BRAND Napa Valley): секция пинится, вертикальный скролл везёт трек
   вбок, по слайду на сорт — бутылка в полный рост, этикетка видна, текст =
   номер + сорт + «Подробнее». Механика: `useHorizontalScroll` (sticky +
   transform). На ≤900px и при reduced-motion — нативный свайп со scroll-snap.
   Полотно перекрашивается в основной цвет сорта (`wine.band` в lib/content.ts)
   с плавной интерполяцией между слайдами; кремовый текст на любом `band`
   должен держать ≥4.5:1.
8. **Scroll-reveal** — единый язык движения: `[data-reveal]` + хук `useReveal`,
   всплытие из 24px за 0.9s по cubic-bezier(0.215, 0.61, 0.355, 1), каскад через
   `--reveal-delay`; `prefers-reduced-motion` отключает.
