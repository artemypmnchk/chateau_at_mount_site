# Спека страницы «О нас» — концепция «Написано вином на известняке»

Утверждённый вектор для полной переработки страницы About. Строим страницу
целиком по этому документу. Тон, палитра и шрифты — из `DESIGN.md`; тексты — из
`docs/about-content-bank.md`.

## 1. Идея одной строкой

Вся страница — **один непрерывный рисунок винной линией по известняковой
бумаге**. Не набор блоков, а один длинный «разворот», который прочерчивается
сверху вниз по мере скролла. Линия отвечает за структуру и движение, винное
пятно — за акцент и ревил.

## 2. Три системы

**2.1. Линия-хребет (структура).** Одна непрерывная линия идёт через всю
страницу как позвоночник и дорисовывается по скроллу, всегда чуть впереди
читателя. Меняет роль от секции к секции, оставаясь одной линией: горизонт холма
→ виноградная лоза → струя розлива → ветка с листом у наград → подпись в финале.
Между секциями нет швов — линия перетекает (родня приёма `melt` на главной). На
десктопе живёт в левом поле, на мобиле — тонкой нитью между блоками.

**2.2. Вино-чернила (акцент и ревил).** Известняк — бумага, вино — чернила.
Заголовки и ключевые слова проступают пятном, впитавшимся в бумагу (пыльная роза
→ винный). Разделители секций — мягкие винные подтёки, не линейки. Единственный
цвет-акцент — винный/роза (железное правило сайта «только винный цвет»).

**2.3. Типографика и движение (как на сайте).** Oranienbaum крупно ведёт,
Piazzolla-курсив — «голос семьи» на подписях и цифрах. Движение единое: линия
рисуется, тексты всплывают (`useReveal`), пятна впитываются.

## 3. Выбранные усиления (все четыре)

- **💧 Капля-прогресс.** По линии стекает капля вина — одновременно индикатор
  прокрутки и «где я сейчас». Точки на линии = секции (опц. кликабельны-якоря).
- **✍️ Подпись в финале.** В конце линия складывается в рукописное
  _Chateau At Mount_ — как подпись на этикетке/письме.
- **🔢 Жидкая заливка цифр.** Даты и числа (2019, 15 га, 150 000…) наливаются
  вином снизу вверх на ревиле.
- **☀️ Свет за скроллом.** Спускаешься по странице — тёплый «солнечный» отсвет
  смещается от утреннего к золотому часу, бумага чуть теплеет. Перекличка с
  «самый солнечный город Молдовы».

## 4. Вау-моменты (оба — как рамка «подпись → подпись»)

- **✒️ Интро-подпись (старт).** Пустой известняк → линия рисуется в реальном
  времени и выводит имя винодельни → страница начинается (≈2 сек, один раз за
  сессию, пропускается кликом/скроллом).
- **🍷 Финальная капля (финал).** Лоза дотягивается до низа, линия подписывает
  имя, срывается капля, падает и распускается в винно-красную кнопку CTA.

## 6. Движение и техника

- **Линия:** один длинный SVG-`path` (или сцепка сегментов), анимация
  `stroke-dasharray`/`stroke-dashoffset`. Прогресс — от позиции секций во
  вьюпорте на passive-скролле в одном rAF-кадре (тот же подход, что в
  `HighlightOnScroll.tsx`), либо нативные CSS scroll-driven animations там, где
  поддержаны.
- **Капля:** позиционируется вдоль пути через `path.getPointAtLength(progress *
totalLength)`.
- **Заливка цифр:** `clip-path`/маска, анимируемая на ревиле (`data-reveal`).
- **Свет:** тёплый радиальный оверлей, чья цветовая температура интерполируется
  по общему прогрессу скролла.
- **Единый язык:** `useReveal` для всплытия текста; никаких новых движков без
  нужды. **Без WebGL** — держим лёгким и мобильным.
- **`prefers-reduced-motion`:** линия статична и дорисована, капля скрыта, цифры
  залиты, свет фиксированный, интро пропущено — страница читается как обычный
  редакционный разворот. То же для SSR без JS.
- **Мобайл:** линия тоньше и по центру между блоками; интро короче; проверить
  перф на слабых устройствах.

## 7. Что переиспользуем из существующего кода

- SVG-сцена из текущей `AboutPage.tsx`: солнце с лучами, растущие гроздья, холмы,
  здание, лоза, лист, усик — доноры узлов, к которым цепляется линия.
- `useReveal`, паттерн `HighlightOnScroll`, плёночное зерно.
- Цвета этикеток вин (`accent`/`band` в `lib/content.ts`) — для блока вин.
