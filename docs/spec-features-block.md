# Спецификация: блок «Пруф» (замена features-карточек)

Статус: **прожарено 10.07.2026, поправки внесены (§9)**. К реализации
по этапам §10 со стоп-точкой после этапа 1.
Исследование: [research-features-block.md](research-features-block.md).
Позиция: главная, светлая глава **после вин-бэнда**, перед «производством»
(решение владельца на чекпоинте этапа 1, 10.07.2026; изначально блок
стоял между манифестом и винами — перенесён, чтобы манифест сразу
передавал в вина, а цифры-пруф подводили к производству).

## 1. Решения владельца (10.07.2026)

| Вопрос                           | Решение                                                                               |
| -------------------------------- | ------------------------------------------------------------------------------------- |
| Жанр блока                       | Гибрид A+C: галерейная развеска двух вертикальных кадров + цифры-герои                |
| Кадры                            | «Сбор урожая» (IMG_3812) + «пикник в лозах» (`feature-vineyards.jpg`); корзина уходит |
| Цифры                            | 15 га · до 150 000 бутылок/год · Est. 2019 (без «7 сортов», без высоты холма)         |
| Строка о вкусе («Даже красные.») | Музейной подписью при кадре пикника                                                   |
| Текст на фото                    | Снимается полностью (правило 1 DESIGN.md)                                             |

Роль блока: слой доказательства между мифом (манифест) и продуктом
(вина) — место и цифры. Название в коде: `.proof`.

## 2. Композиция секции

Известняк `--bg`, обычные секционные отступы (инлайновый `paddingTop: 0`
убираем — сверху теперь тёмный манифест, нужна полная пауза). Всё в
`.container`. Сверху вниз:

1. **Киккер** `.eyebrow`: «Наш холм» (плейсхолдер, финал за владельцем).
   Заголовка h2 нет — типографический герой блока ниже, цифры;
   второй заголовок съел бы их вес (прецедент: манифест без h2).
2. **Развеска** — асимметричная сетка из двух вертикальных кадров:
   - Кадр A «Сбор урожая» — крупнее: 7 колонок из 12, соотношение 3:4.
   - Кадр B «Пикник» — меньше: 4 колонки, соотношение 4:5, смещён вниз
     на ~72px (галерейная развеска, не журнальная сетка).
   - Между ними — пустая колонка воздуха.
   - Кадры чистые: без текста, скримов, ссылок и hover-зума.
     Радиус `var(--radius)` (2–3px).
   - Под каждым кадром музейная подпись: микролейбл капсом
     (12px, разрядка — легальное место по правилу 6) + строка
     `--ink-soft` 15px:
     - A: «СБОР УРОЖАЯ» / «Сентябрь, вершина холма»
     - B: «СТИЛЬ ВИН» / «С выразительной кислотностью и свежими
       фруктовыми нотками. Даже красные.» (лейбл НЕ «Наши вина» —
       дубль киккера вин-бэнда прямо под блоком, см. прожарку §9.1)
3. **Строка цифр** — под развеской, отступ ~96px, три фигуры:
   - `15` — ГЕКТАРОВ ВИНОГРАДНИКОВ
   - `150 000` — БУТЫЛОК В ГОД (перед цифрой префикс «до» мелким,
     стилем микролейбла — честность формулировки сохраняем)
   - `2019` — ГОД ОСНОВАНИЯ
   - Цифры: Piazzolla 500, `clamp(48px, 7vw, 96px)`, `line-height 1`.
     Оптический размер — та же ручка, что в манифесте
     (`font-variation-settings: "opsz"`), подбираем на чекпоинте.
     Никаких требований к tabular-nums — это не таблица, у Piazzolla
     их может не быть (снято прожаркой §9.2).
   - Микролейблы под цифрами: капс, 12px, разрядка, `--ink-soft`.
   - Раскладка: три колонки по левым краям, между ними воздух;
     тонкие вертикальные линии `var(--line)` — опция, решаем на живом
     рендере (по умолчанию без линий).
   - Никакого count-up (приём дашбордов — осознанно не делаем).

## 3. Движение

Единый язык `[data-reveal]` + `useReveal` (правило 8 DESIGN.md):
киккер → кадр A → кадр B (каскад через `--reveal-delay`, шаг ~120ms) →
цифры (свой каскад 3 × 80ms). Ничего нового не изобретаем;
`prefers-reduced-motion` отключается существующей системой.

## 4. Адаптив

- **≤1024px:** сдвиг кадра B уменьшается до ~40px, цифры
  `clamp(40px, 8vw, 72px)`.
- **≤900px:** развеска в столбик: кадр A, подпись, кадр B, подпись
  (смещения нет). Цифры — вертикальный столбик с левым выравниванием,
  межцифровой отступ 40px; либо, если влезают, строка — проверяем на 375.
- **≤540px:** кадры full-width контейнера, соотношение 4:5.
- Число «150 000» — самая широкая фигура: на 375px при 48px должна
  влезать в контейнер (проверка скриншотом).

## 5. Контент (lib/content.ts)

Ключи `features.*` умирают, вместо них `proof.*` (ru/en/ro):

- `proof.kicker`: «Наш холм» / “Our hill” / „Dealul nostru”
- `proof.captions.harvest.label`: «Сбор урожая» / “Harvest” / „Culesul”
- `proof.captions.harvest.text`: «Сентябрь, вершина холма» /
  “September, the top of the hill” / „Septembrie, vârful dealului”
- `proof.captions.taste.label`: «Стиль вин» / “The style” / „Stilul vinurilor”
- `proof.captions.taste.text`: «С выразительной кислотностью и свежими
  фруктовыми нотками. Даже красные.» / “Expressive acidity and fresh
  fruity notes. Even the reds.” / „Aciditate expresivă și note proaspete
  de fructe. Chiar și cele roșii.”
- `proof.figures` — массив из трёх: `{ value, prefix?, label }`;
  значения-строки с неразрывными пробелами («150 000»), «до»/“up to”/
  „până la” — в `prefix` второй фигуры.
- alt-тексты кадров.

В цифрах и подписях проставить неразрывные пробелы.

## 8. Критерии приёмки

1. Никакого текста и скримов поверх фотографий; подписи — под кадрами.
2. Цифры — самый крупный элемент блока, соизмеримы с h2 соседних глав
   (≥48px на 375, ≥88px на 1440).
3. Вина → пруф → производство читаются как тьма → свет → тьма, блок не
   выглядит прицепом (нормальный верхний отступ); стык манифест → вина
   (тьма → тьма) держится сменой жанра: типографика → сцена.
4. Развеска асимметрична (видимый сдвиг кадров на десктопе), но на
   ≤900px не разваливается.
5. «150 000» не переносится и не вылезает на 375px.
6. Reveal-каскад в общем языке; reduced-motion — статика.
7. Радиусы ≤3px, никаких пилюль/иконок; разрядка только в капс-лейблах.
8. tsc чистый, консоль чистая, layout shift отсутствует
   (у кадров заданы соотношения).

## 9. Поправки после прожарки (обязательные к реализации)

1. **Дубль микролейбла.** Подпись кадра B была «НАШИ ВИНА» — ровно
   киккер вин-бэнда (`winesSection.eyebrow`), который начинается сразу
   под блоком. Заменено на «СТИЛЬ ВИН» / “THE STYLE” / „STILUL VINURILOR”.
   Внесено в §2 и §5.
2. **tabular-nums снят.** Это не таблица; у Piazzolla табличных цифр
   может не быть, требование фиктивное. Внесено в §2.
3. **Геометрия развески — чекпоинт, а не догма.** При A=7 колонок (3:4)
   и B=4 колонки (4:5) разница нижних кромок ≈400px — правый низ может
   зиять. Пропорции в §2 — стартовые; на чекпоинте этапа 1 крутим три
   ручки: ширины колонок (вплоть до 6/5), соотношения кадров,
   величину сдвига B — до состояния «развеска, а не дыра».
   Плюс `object-position` подбирается по фактическим кадрам (у пикника
   героини в нижней половине кадра — центр-кроп 4:5 может резать головы).
4. **Базовая линия префикса «до».** Префикс сидит на базовой линии
   большой цифры (инлайновый `span` меньшего кегля, никаких
   `vertical-align: top`), иначе получится «степень».
5. **Длина блока на мобиле.** Два портретных кадра full-width + подписи
   - столбик цифр на 375px — ~3 экрана. Принимаем как черту редакционного
     стиля, но на чекпоинте смотрим скриншот 375 целиком; запасная ручка —
     на ≤540px кадры 3:4 вместо 4:5 (ниже) и цифры компактнее.
6. **EXIF-ориентация.** После `sips -Z 2560` проверить, что harvest.jpg
   не лёг набок (портрет 3923×5885 снят с поворотом в метаданных).
7. **`sizes` у кадров.** A: `(max-width: 900px) 100vw, 60vw`;
   B: `(max-width: 900px) 100vw, 36vw` — чтобы next/image не тянул
   полноразмер в узкую колонку.

Замечание без правки: киккер «Наш холм» повторяет слово «холм» из
манифеста прямо над блоком. Осознанно — это лейтмотив сайта; если на
живой проверке прозвучит как заикание, у владельца есть свобода
переписать киккер в `lib/content.ts` без кода (§9).

## 10. Декомпозиция: этапы, каждый — атомарный коммит

### Этап 1 — «Статика» → СТОП-ТОЧКА

Подготовка фото (ужать/переименовать harvest.jpg, проверить ориентацию,
`git add` только его) + ключи `proof.*` в контенте + разметка секции

- CSS развески и цифр. Reveal пока не вешаем. Старые стили/ключи не
  трогаем (удаление — этап 2, чтобы диффы читались раздельно).
  Проверка: скриншоты 375/768/1280/1440 + стык манифест→пруф→вина;
  подбор ручек: opsz цифр, геометрия развески (§10.3), «до» на базовой
  линии; «150 000» без переноса на 375; tsc чистый.
  **Выход: скриншоты владельцу, ждём «ок» по геометрии и цифрам.**

### Этап 2 — Движение и зачистка

`data-reveal`-каскад (§3); удаление `.features`/`.feature-card*` из CSS,
ключей `features.*` из контента, импорта `basketImg` (файл — после
проверки других использований); удаление старой разметки, если что-то
осталось. Проверка: reveal в обе стороны прокрутки, reduced-motion,
консоль и tsc чистые, layout shift отсутствует; финальные скриншоты
375/768/1280/1440.

## 11. Вне скоупа

- Панорама холма: когда появится — блок штатно упрощается до чистого
  варианта A (развеска → один кадр), цифры не меняются.
- Судьба остальной свежей фотопачки (разбор под «Семью»/«Мероприятия»).
- Тексты киккера/подписей — плейсхолдеры, владелец может переписать
  без кода (только `lib/content.ts`).
