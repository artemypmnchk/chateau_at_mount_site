## 1. Решения владельца

| Вопрос | Решение |
|---|---|
| Жанр блока | Типографический манифест (не сплит с фото) |
| Фон | Тёмный, слива `--dark #1e1518` |
| Шрифт фразы | Piazzolla (вес/opsz подбираем на чекпоинте этапа 1) |
| Механика | M2b — мягкое пословное проявление по скроллу |
| Розовый акцент на ключевых словах | Да (этап 3, откатываемо) |
| Фраза | №2 как плейсхолдер, **текст будет переписан владельцем** |
| Фото «урожай + семья» | Убрать с главной; секция «Семья» появится позже |
| Факты (15 га, 7 сортов) | Тихая строка-микролейбл под ссылкой |
| Ссылка | «Приехать в гости» → `/visit` |

## 2. Композиция секции

Сверху вниз, всё в `.container`, выравнивание влево (как хиро):

1. Киккер-микролейбл «О винодельне» (стиль `.eyebrow`, на тёмном —
   пыльная роза `--accent`).
2. **Фраза-манифест**: Piazzolla, `clamp(40px, 6vw, 72px)`,
   `line-height 1.12`, `max-width ~13em`, кремовый `--bg` в подсвеченном
   состоянии. Стартовые параметры шрифта — вес 500; на чекпоинте этапа 1
   подбираем ручки из §6.1.
3. Ссылка «Приехать в гости →» — тихая подчёркнутая ссылка на тёмном
   (как `.hero-link` / `.band-all`), НЕ пилюля (правило 6 DESIGN.md).
4. ~~Микролейбл фактов~~ — **удалён по решению владельца после живой
   проверки (10.07.2026)**: блок = киккер + фраза + ссылка.

Секция: `min-height: 70vh` на десктопе, контент отцентрован по вертикали,
щедрые отступы (низ ≥ `clamp(96px, 12vh, 160px)`). На мобильных —
обычные секционные отступы, без принудительной высоты.

**Два языка движения не смешиваем:** киккер, ссылка и факты получают
обычный `data-reveal`; фраза — **только** пословное проявление, без
reveal-всплытия.

**Стык с хиро:** низ хиро — светлое поле травы, дальше плоская слива:
будет жёсткая горизонтальная линия. Принимаем как «монтажную склейку»,
но проверяем скриншотом стыка на чекпоинте этапа 1 (скрим поверх фото
не добавляем — правило 1 DESIGN.md).

**Награды ниже:** у секции наград сейчас `paddingTop: 0` — рассчитано на
светлый about сверху. После тёмного манифеста вернуть наградам верхний
отступ (обычный секционный или согласованный меньший). Содержимое наград
не трогаем.

## 3. Механика M2b (пословное проявление)

Один слой текста, без дублирования:

- Фраза режется на слова-обёртки (переносы, акценты), внутри — **буквы**-
  `<span>` (побуквенно — по фидбеку владельца 10.07.2026: плавнее, чем
  пословно). База: `opacity: var(--dim)` (0.18 после живой проверки),
  `transition: opacity 0.45s ease`. Класс `.lit` → `opacity: 1`.
- Прогресс: невидимый якорь + IntersectionObserver с порогами по буквам
  (`[0, 1/N, …, 1]`, N ≈ 70–90). Постоянных scroll-листенеров нет.
- Догон цели — адаптивный шаг (`max(1, |diff|/6)` букв за кадр): быстрый
  скролл даёт бегущий свет без полуторасекундного доползания.

### Поправки после прожарки (обязательные к реализации)

- **Кап якоря.** Высота якоря = `min(высота секции, 55vh)`, позиция — от
  вертикального центра секции. Прогресс нормируется на максимально
  достижимый ratio (`maxRatio = min(1, viewportH / anchorH)`), иначе на
  экранах ниже секции хвост фразы не загорится никогда.
- **Поведение симметричное** (пересмотрено владельцем на живой проверке
  10.07.2026: вариант «вниз только зажигаем» ощущался как «анимация не
  возвращается»). Прогресс следует за видимостью якоря в обе стороны —
  фраза гаснет и разжигается при каждом проезде, как у BRAND.
- **Заметность эффекта**: якорь фикс. 55vh, **начинается от верха фразы**
  (не по центру — иначе зажигание стартует до появления фразы на экране,
  и первая строка входит уже зажжённой); `--dim` опущен до 0.18. Кап 55vh
  одновременно гарантирует достижимость ratio = 1 на любом экране.
- **Догон — микро-rAF, самозатухающий.** Последовательное зажигание
  («бегущий свет», а не вспышка пачкой) требует тикера: rAF-цикл живёт
  **только пока** `currentIndex !== targetIndex`, делает ±1 слово за кадр
  и останавливается. В покое и вне секции — ноль работы. Это осознанное
  отступление от «никаких rAF» — без него быстрый скролл зажигает абзац
  одной вспышкой.
- **Инициализация без вспышки.** SSR рендерит все слова зажжёнными.
  На гидрации не гасим всё в 0: первый замер IO задаёт стартовый прогресс
  (важно при открытии страницы с восстановленным скроллом или по якорю
  `#about`).

Деградация:
- `prefers-reduced-motion` — наблюдатель не подключаем, все слова `.lit`.
- Без JS — серверная разметка полностью зажжена, блок читается.
- Скринридеры: opacity не скрывает текст из accessibility tree, фраза
  читается единым абзацем.

## 4. Контент (lib/content.ts)

Новый ключ `about.manifesto` (старые `about.*` ключи удаляем вместе с
разметкой сплита; перед удалением фото-импортов `harvestImg`/`familyImg`
проверить другие использования).

Разметка акцентов — `*звёздочками*`, компонент парсит. **Обязательный
комментарий рядом с ключом** — правило разметки, иначе при переписывании
фразы владельцем акценты потеряются.

Плейсхолдеры (все три будут переписаны):

- ru: «Мы делаем вино там же, где оно растёт: один *холм*, одна *семья* —
  весь путь от лозы до бутылки»
- en: “We make wine where it grows: one *hill*, one *family* — the whole
  journey from vine to bottle”
- ro: „Facem vinul acolo unde crește: un *deal*, o *familie* — întregul
  drum de la viță la sticlă”

**Примечание к переписыванию** (из прожарки): текущая фраза — смысловой
парафраз премисы BRAND («wines that root deepest where they're grown…»).
При финальном тексте уйти от формулы «вино ↔ место укоренения»: искать
свой миф (солнце на вершине, семья, въезд в город — материала хватает).
В контенте проставить неразрывные пробелы (предлоги, «Чадыр-Лунга»).

## 6. Принятые риски и исключения (фиксируем честно)

1. **WCAG-контраст приглушённых слов** — формально не проходит никогда.
   Осознанное дизайн-исключение (тот же приём у BRAND и Apple): полный
   текст доступен в DOM, при reduced-motion и без JS — полностью зажжён,
   зажжённое состояние держит ≥4.5:1.
2. **Главная остаётся без людей** до появления секции «Семья»: в features
   — виноградник и корзина. Решение владельца, риск позиционирования
   назван и принят.
3. **Две тёмные секции подряд** (хиро + манифест): разделение жанром
   (фото → плоская типографика). Проверяется скриншотом стыка; если
   выглядит «кончилась картинка» — обсуждаем на стоп-точке.
4. `#about` в навигации теперь ведёт на манифест; когда появится страница
   истории — переадресуем пункт меню туда.

### 6.1. Шрифтовые ручки для чекпоинта этапа 1

Главный риск спеки: волосяные засечки variable-Piazzolla на большом кегле
могут рассыпаться в приглушённом состоянии на сливе. Подбираем на живом
рендере, в порядке предпочтения:

1. Зафиксировать оптический размер: `font-variation-settings: "opsz" 28`
   (номинал на 72px даёт слишком тонкие штрихи).
2. Вес 560–600 вместо 500.
3. Базовая непрозрачность `--dim` 0.32 → до 0.4.

Если ни одна комбинация не держит — стоп, разговор о смене шрифта фразы
(решение владельца, см. DESIGN.md «никаких новых шрифтов»).

## 7. Декомпозиция: этапы, каждый — атомарный коммит

### Этап 1 — «Статика» (без механики) → СТОП-ТОЧКА
Контент-ключи + разметка секции + CSS; все слова в `.lit`; отступ наград.
Компонента механики ещё нет — фраза обычным абзацем.
Проверка: скриншоты 375/768/1280/1440 + **отдельный скриншот стыка
хиро→манифест**; подбор шрифтовых ручек §6.1; tsc чистый.
**Выход: скриншоты владельцу, ждём «ок» по шрифту и стыку.**

### Этап 2 — Механика проявления
`HighlightOnScroll.tsx` со всеми поправками §3 (кап якоря, нормировка,
реверс-логика, самозатухающий rAF-догон, инициализация без вспышки,
reduced-motion).
Проверка: обе стороны скролла; быстрый скролл (нет «вспышки абзаца»);
мобильный кейс «секция выше вьюпорта» — хвост фразы загорается; открытие
страницы сразу на манифесте — нет вспышки гашения; консоль чистая.

### Этап 3 — Акцентные слова
Парсер `*акцентов*` + курсив + роза `--accent` в `.lit`-состоянии.
Проверка: скриншот; решение владельца оставить/откатить (изолированный
коммит — откат тривиален).

### Этап 4 — Зачистка и финал
Удаление мёртвых стилей/ключей/фото-импортов; проверка `.about-link` и
`harvestImg`/`familyImg` на другие использования; tsc; reduced-motion;
отсутствие layout shift; финальные скриншоты 375/768/1280/1440.

## 8. Критерии приёмки

1. Хиро → манифест → вина прокручиваются как один фильм: нет ощущения
   «сменился сайт» и «второй обложки».
2. Крупность фразы соизмерима с хиро (≥40px на 375px, ≥64px на 1440px).
3. Проявление: вниз — только зажигается, вверх — гаснет; на любом
   вьюпорте фраза загорается целиком; быстрый скролл даёт бегущий свет,
   а не вспышку.
4. При reduced-motion и без JS блок полноценно читается.
5. В блоке ≤ 4 сущностей: киккер, фраза, ссылка, строка фактов.
6. Никаких пилюль, кругов, залитых кнопок; радиусы ≤ 3px.
7. Награды ниже не прилипают к тёмному краю.

## 9. Вне скоупа

- Содержимое наград (следующий разговор) — но их верхний отступ чиним
  (§2), это часть стыка.
- Переписывание фразы — отдельная задача владельца (с учётом примечания §4).
- Секция «Семья» — когда будет контент.
- `follow-image` за курсором — возможная пасхалка потом.
