# Исследование: блок под хиро как типографический манифест

Статус: исследование, код не трогаем. На основе этого документа вместе
составляем финальную спецификацию. Собрано 10.07.2026.

Предыдущая спека — [spec-about-block.md](spec-about-block.md) (v3, параллакс
фото-пары). Это направление ей альтернативно: не «оживить сплит», а заменить
жанр блока. Старую спеку не удаляем до решения владельца.

## 1. Диагноз: почему текущий блок «дешевит»

Смотрели живой сайт (1280×800) и сравнивали три «главы» подряд.

1. **Провал масштаба.** Hero h1 — `clamp(56px … 128px)`, заголовок блока вин —
   `clamp(32px … 56px)`, а about h2 — `clamp(30px … 50px)`. Блок между двумя
   кинематографичными сценами — самый мелкий на странице.
2. **Жанровый разрыв.** Хиро и вина — «сцены»: один герой, тьма, движение,
   привязанное к скроллу. About — журнальный шаблон: колонка текста + фото с
   врезкой-полароидом и box-shadow. Именно «сплит с врезкой внахлёст» —
   стандартный приём шаблонов/AI-генераций, отсюда ощущение дешевизны.
3. **Плотность контента.** Киккер + заголовок + курсив + абзац + ссылка +
   две фотографии + вертикальная подпись — семь сущностей. У дорогих сайтов
   в этой позиции одна мысль и одно действие.
4. **Нет языка движения.** У хиро — заезд и scroll-подсказка, у вин —
   горизонтальный проезд по скроллу. У about — только fade-in при появлении.

## 2. Разбор референса: BRAND Napa Valley

Блок сразу после хиро — «манифест»: одна фраза на весь экран, слова
подсвечиваются по мере скролла (серый → белый), под фразой одна кнопка
«Our Manifesto». Разобрали исходники (Nuxt, компонент `HighlightOnScroll`).

### Композиция
- Секция: чёрный `#070707`, на десктопе `min-height: 700px`, контент
  отцентрован по вертикали, гигантские отступы сверху/снизу.
- Внутри **ровно два элемента**: фраза (~18 слов) и ссылка-кнопка. Всё.
- Фото в блоке нет вообще — фотографии живут в следующей секции.

### Типографика
- Desktop: `--step-5 = clamp(2.57rem … 4.73rem)` ≈ **41→76px**, гротеск
  Neue Haas Unica 700, `line-height: 1.1`. Mobile — ступень ниже.
- Цвета: не подсвеченный текст — серый `rgb(153 153 153)` на чёрном,
  подсвеченный — белый. Контраст мягкий, не «выключенный» текст.

### Механика подсветки (главная находка)
Никакого scroll-листенера и никакого rAF:

1. Фраза рендерится дважды, слово в слово: нижний `<p>` — серый, полный
   текст; верхний `<p>` — `position:absolute; top:0`, белый,
   `aria-hidden="true"`, изначально пустой.
2. В секции лежит невидимый «якорь» (полоска 20px шириной, высота 100%
   секции, `top:50%`, `opacity:0`).
3. На якорь вешается **IntersectionObserver с массивом порогов по границам
   слов** (`threshold: [0, 1/N, 2/N, …, 1]`). Прогресс = intersectionRatio.
4. `index = floor(progress × N)`; верхний `<p>` получает первые N слов.
   Индекс догоняет цель по ±1 за тик — слова загораются последовательно
   даже при быстром скролле, и гаснут при скролле вверх.
5. Поскольку оба абзаца — один и тот же текст тем же шрифтом, белые слова
   ложатся поверх серых пиксель в пиксель.

Дёшево (браузер сам считает пересечения), плавно, обратимо, деградирует
изящно: без JS остаётся серый полный текст.

Бонус-деталь у BRAND: за курсором в зоне манифеста может плыть картинка
~250px (`follow-image`, только desktop). Опционально, в первую итерацию
не берём.

### Почему это не противоречит уроку v2
v2 («тёмный full-bleed пролог») провалился, потому что после фото-хиро шла
**ещё одна фотография** — читалось как «вторая обложка». У BRAND тёмный блок
после хиро работает, потому что это **чистая типографика на плоском фоне**:
смена языка (фото → буквы) сама по себе даёт монтажную склейку, даже без
смены светлоты.

## 4. Как перенести в нашу систему (варианты на обсуждение)

Общее для всех вариантов: одна фраза-миф (~12–20 слов), масштаб уровня хиро
(`clamp(40px … 72–80px)`, `line-height 1.1–1.15`), подсветка слов по скроллу
механикой BRAND, под фразой — одна тихая ссылка нашего стиля (подчёркивание
+ стрелка; **не пилюля** — правило 6 DESIGN.md). Киккер «О винодельне»
оставить микролейблом.

### Вариант A — тёмный манифест (ближе всего к BRAND)
Фон `--dark #1e1518` (слива), текст: не подсвеченный ≈ `#6a5a5e` (пыльный на
сливе), подсвеченный — кремовый `#f4f1ea`. Кино непрерывно: тёмный хиро →
тёмный манифест → (свет) → глиняные вина.
- Риск: тьма подряд (урок v2). Митигация — плоский фон без фото и явная
  смена жанра; при желании тонкая линия/киккер как «титр главы».
- Вопрос: куда девается светлая «глава» — тогда светлыми остаются награды
  и features ниже.

### Вариант B — известняковый манифест (сохраняем светлую главу)
Та же механика на `--bg #f4f1ea`: не подсвеченные слова — тёплый серый
(~`#b9b0a2`, тон известняка темнее), подсвеченные — `--ink #241a1c`.
Ритм светлоты страницы не меняется вовсе; дороговизну даёт масштаб и жест.
- Риск: на светлом эффект подсветки менее «вау», чем на тёмном.
- Плюс: не конкурирует с хиро и винами за тьму, монтаж «тьма → свет → тьма»
  сохраняется.

### Вариант C — манифест + компактный сплит ниже (гибрид)
Манифест (A или B) как первая секция, а нынешний сплит с фото-парой
ужимается до короткой строки фактов + фото и уезжает ниже по странице
(или частично в features). Больше работы, зато семья и цифры не пропадают
с главной.

### Куда деть текущий контент (если манифест «съедает» блок)
- `line1` (заголовок) + `voice` (курсив) → сплавляются в одну фразу-миф.
- `line2` (15 га, семь сортов) → строка-микролейбл под ссылкой манифеста
  или в features/visit.
- Фото «урожай + семья» → features-карточки уже есть; либо вариант C.
- Вертикальная подпись «Est. 2019 · Чадыр-Лунга» — хороший кандидат остаться
  деталью манифеста (край секции), она уже «дорогая».

## 5. Черновик механики (для будущей спеки)

- `components/HighlightOnScroll.tsx` — клиентский компонент: принимает
  `text`, рендерит два слоя + якорь, IntersectionObserver с порогами по
  словам. Слова получаем `text.split(" ")` — для ru/en/ro работает одинаково;
  в контенте проставить неразрывные пробелы там, где нельзя рвать строку
  («Чадыр-Лунгу», предлоги).
- `prefers-reduced-motion`: наблюдатель не подключаем, текст сразу полный
  «подсвеченный». Без JS — виден серый полный текст (SSR-friendly).
- Никаких rAF/scroll-листенеров — дешевле и надёжнее параллакса из спеки v3.
- CSS: секция-глава `min-height ~70vh` desktop, вертикальное центрирование,
  `max-width` фразы ~13–14em, отступы уровня хиро.
- Piazzolla 500 в этом масштабе — проверить скриншотом первым же шагом:
  у BRAND жирный гротеск, у нас серифный голос (ближе к Realm). Если серif
  «поплывёт», кандидат — Inter 600/650 как «манифестный» санс, но это
  решение владельца (правило: никаких новых шрифтов без решения).

## 6. Критерии приёмки (черновик)

1. При прокрутке хиро → манифест → вина нет ощущения «сменился сайт»
   (главный критерий из спеки v3, остаётся).
2. Крупность фразы соизмерима с хиро (низ вилки ≥ 40px, верх ≥ 64px).
3. Подсветка идёт за скроллом в обе стороны, без дёрганья; при
   reduced-motion и без JS блок полноценно читается.
4. В блоке не больше трёх сущностей: киккер, фраза, ссылка (+опционально
   вертикальная подпись).
5. 375 / 768 / 1280 / 1440 — скриншоты; tsc и консоль чистые.

# Раунд 2 — варианты механики, не копируя BRAND

## 8. Что делают другие в этой позиции (проверено по живым сайтам)

Типология «блока после хиро» у премиальных виноделен:

| Тип | Кто | Как |
|---|---|---|
| Кинетический манифест | BRAND | Гигантский гротеск 41–76px, пословная подсветка по скроллу, 1 кнопка |
| Тихий серифный манифест | Realm Cellars | **Garamond 22–32px**, длинная мысль (~50 слов), по центру, простой fade-in 1s. Никакого скролл-эффекта |
| Центрированный statement | Darioush | Одна фраза-кредо по центру + ссылка «our vision» со стрелкой, статично |
| Сразу коммерция | Silver Oak | Два флагмана с ценой и Add to Cart |
| Плитка CTA | Epoch | Шесть навигационных блоков |

Вывод: «дорого» достигается двумя противоположными способами — **жестом**
(BRAND: масштаб + движение) или **выдержкой** (Realm: сериф, воздух,
неторопливость). Оба работают; дешевит только середина — journal-сплит
с фото-врезкой (наш текущий).

## 9. Меню механик для нашего тёмного Piazzolla-манифеста

Все варианты: слива `--dark #1e1518`, Piazzolla 500, одна фраза, одна
тихая ссылка, вертикальная подпись «Est. 2019 · Чадыр-Лунга · Гагаузия»
как деталь края. Отличается только поведение текста.

### M1 — «Выдержка» (Realm-путь, без скролл-механики)
Фраза `clamp(34px … 56px)`, по центру или влево, каскадный reveal нашей
существующей системой (`data-reveal`, построчные задержки). Ноль нового JS.
- Плюсы: самый дешёвый и надёжный; серифу идёт неторопливость.
- Минусы: не отвечает на «нет языка движения» — блок снова статичен,
  просто крупнее и темнее. Риск повторить судьбу v1/v2.

### M2 — Пословная подсветка (BRAND-механика как есть)
Описана в §2. Бинарное переключение серый→кремовый по словам.
- Плюсы: проверено; дёшево (IntersectionObserver).
- Минусы: это «фирменный» приём BRAND и апстора Apple — узнаваемое
  заимствование; бинарное переключение суховато для серифа.

### M2b — Мягкое «проявление» слов (наша интерпретация — рекомендую)
Та же основа (два слоя не нужны!): фраза режется на `<span>` по словам,
у каждого `opacity: 0.24; transition: opacity 0.45s ease` (приглушённый
сливово-серый), класс `.lit` даёт `opacity: 1` (кремовый `--bg`).
Прогресс — тот же IntersectionObserver с порогами по словам, слова
«проявляются» с мягким перетеканием, как свет по строке, а не выключатель.
Плюс наша деталь: **1–2 ключевых слова** («солнца», «холма») в курсивном
Piazzolla и при подсветке получают пыльную розу `--accent #d0a09b` —
связка с киккерами тёмных секций. Это уже не BRAND: другой шрифт, другая
пластика, акцентные слова.
- Плюсы: следует порядку чтения; серифу идёт «свет», а не «переключение»;
  выглядит своим, а не заимствованным.
- Минусы: чуть больше DOM (спаны), следить за переносами (`white-space`
  внутри спана + неразрывные где нужно).
- Contrast-check: приглушённое состояние (opacity 0.24 кремового на сливе
  ≈ #4a3f42 на #1e1518) — декоративный слой, полный текст остаётся в DOM
  читаемым для SR; подсвеченный кремовый держит ≥4.5:1.

### M3 — Построчная шторка (line-mask reveal)
Строки фразы поднимаются из-под масок с каскадом при входе в вьюпорт
(одноразово), дальше текст статичен.
- Плюсы: классика дорогих сайтов (портфель FINE), эффект «печати».
- Минусы: одноразовый — при повторном проезде блок мёртв; строки надо
  резать JS-ом по фактическим переносам (хрупко при ресайзе/локалях).

### M4 — Скролл-зависимая пластика фразы (scale/tracking)
Фраза чуть «дышит» по мере проезда: scale 0.97→1, letter-spacing
сжимается. Продолжение языка вин-бэнда (rAF-прогресс).
- Плюсы: движение без подсветки, ни на кого не похоже.
- Минусы: эффект тонкий до незаметности, а сериф при непрерывном scale
  мылится на не-retina; rAF-хук — снова бюджет производительности.

### Не делаем (осознанно)
- Пиннинг секции — конкурирует с вин-бэндом (уже решено в спеке v3).
- Фото/видео-подложка под текстом — урок v2.
- Микро-фото между словами фразы (журнальный приём) — клише 2025 года,
  на кириллице с переносами хрупко.
- Картинка за курсором (BRAND `follow-image`) — отложить; можно добавить
  позже как пасхалку, если блок покажется пустым.

**Рекомендация: M2b.** Если хочется совсем без скролл-механики — M1,
но тогда весь эффект держится на масштабе и это надо проверять скриншотом
первым шагом.

## 10. Черновики фразы (Piazzolla, ru — финал согласуем)

Критерии: одна мысль, 12–18 слов, читается голосом семьи, содержит «миф
места» (холм, солнце, семья, весь путь на одном месте). Ключевые слова
для розового акцента выделены *курсивом*.

1. «Вино начинается с места. Наше растёт на самой высокой точке *холма*,
   где *солнца* больше всего» — прямое развитие текущего voice, миф места.
2. «Мы делаем вино там же, где оно растёт: один *холм*, одна *семья* —
   весь путь от лозы до бутылки» — миф целостности, перекликается с
   премисой BRAND, но своими словами.
3. «Есть холм при въезде в Чадыр-Лунгу. На его самой *солнечной* точке
   мы посадили свои первые *лозы*» — сказочный зачин, самый «фамильный».
4. «*Солнце* задерживается на вершине холма дольше всего — поэтому наши
   *лозы* живут именно здесь» — самый короткий, образ один и сильный.

Моя рекомендация — **№2** (философия, а не описание; хорошо ложится на
пословное проявление) с №4 как запасным.
